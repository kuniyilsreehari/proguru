# proguru

A premium workspace containing two interactive, state-of-the-art sample web applications designed using modern front-end capabilities, custom CSS layouts, and vanilla JS integrations.

## Applications Included

### 1. Antigravity OS
A futuristic, spatial operating system landing page.
*   **Interactivity**: Real-time telemetry indicators, rotating neural visualizer loops, and a custom canvas rendering falling matrix code streams.
*   **Interactive CLI Console**: Run developer diagnostics commands directly:
    *   `sysinfo` - shows platform, host, and kernel versions.
    *   `gravity` - disengages system gravity physics, launching a zero-gravity drift animation across the page.
    *   `matrix` - dynamically switches views into the matrix sandbox canvas.
    *   `neon` - triggers pulse color overrides.
    *   `clear` - clears history.

### 2. Aethera (Zero-Typing ML Platform)
A modular playground for setting up and running AI models without using a keyboard.
*   **Interactivity**: Point-and-click prompt matrix builder, parameter tuning dials, and dynamic node connections demonstrating data execution flows.
*   **Speech Recognition (Web Speech API)**: Dictate prompts verbally to instruct models hands-free.
*   **Text-to-Speech (TTS Reader)**: Synthesis reader reads output responses back to you aloud.

## Local Development

Start the development server using:

```bash
# Install dependencies
npm install

# Start Vite dev server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
